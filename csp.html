💻 Computer Science

AP Computer Science Principles

An introductory course exploring computing's role in the world. Less math-heavy than AP CS A — focuses on big ideas, programming concepts, data, and the societal impact of technology. Great entry point.

📅 Exam: May ⏱ 2 hours Difficulty: Medium ~70% pass rate (score 3+)

📚 The 5 Big Ideas

Creative Development (CRD)

How programs are designed and developed collaboratively. Understand the iterative design process, the value of testing and debugging, and how to document a program's purpose, function, and development.

Data (DAT)

How data is stored (binary, bits, bytes), compressed, and processed to extract information. Understand the difference between data and metadata, and how programs use data to find patterns and draw conclusions.

Algorithms & Programming (AAP)

Variables, conditionals (if/else), loops (for/while), procedures (functions), lists, and algorithm design. Be able to trace through pseudocode and identify the output of a given sequence of instructions.

Computing Systems & Networks (CSN)

How the internet works — packets, IP addresses, DNS, HTTP, routing. Understand fault tolerance, redundancy, bandwidth, and the difference between the internet and the World Wide Web.

Impact of Computing (IOC)

Beneficial and harmful effects of computing innovations, digital divide, cybersecurity threats (phishing, malware, encryption), intellectual property (copyright, Creative Commons), and legal/ethical issues.

🔑 Must-Know Vocabulary

BinaryBase-2 number system; all data is stored as 0s and 1s
AbstractionHiding complex details; focusing on what a program does, not how
AlgorithmA finite set of instructions that accomplish a specific task
Lossless CompressionReduces file size without losing any data (e.g., ZIP files)
Lossy CompressionReduces file size by permanently removing data (e.g., JPEG)
BandwidthMaximum data transfer rate of a network or internet connection
PacketA small chunk of data transmitted over a network independently
EncryptionConverting data into a coded format to prevent unauthorized access
HeuristicA problem-solving approach that finds a "good enough" solution fast
MetadataData about data — e.g., when a photo was taken, where, at what resolution

💡 Study Tips

  • Start your Create Performance Task (CPT) early — ideally weeks before it's due. You need to write a program with a list, a procedure with a parameter, and a written response. Rushing it is the #1 mistake students make.
  • Practice tracing pseudocode on paper. The exam uses its own pseudocode syntax. Work through sample problems slowly and write down the value of each variable after every line. Speed comes with practice.
  • Learn binary conversion. Be able to convert between binary and decimal, and understand how adding one more bit doubles the number of values you can represent.
  • Understand the internet conceptually. Know the difference between the internet (hardware/infrastructure) and the web (HTTP, websites). Understand why packet switching is fault-tolerant.
  • Don't overlook the Impact sections. IOC questions on copyright, privacy, cybersecurity, and the digital divide often appear in clusters. Read about real computing innovations and think through their benefits AND harms.
